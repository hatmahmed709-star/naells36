# لواء 36 - Android Offline App

مشروع Android يفتح واجهة عربية محلية داخل WebView. يحتوي `app/src/main/assets/index.html` على نسخة مبسطة للتشغيل Offline، بينما توجد نسخة المصدر المنقحة من الصفحة المقدمة في `source/اللواء 36.html`.

## بناء التطبيق

1. افتح المستودع في Android Studio وانتظر مزامنة Gradle.
2. اختر **Build → Build APK(s)**.
3. يوجد APK الناتج عادةً في `app/build/outputs/apk/debug/`.

## تشغيل Offline وتحميل البيانات

- التطبيق لا يحتاج إذن إنترنت.
- النسخة المبسطة تقبل CSV بترميز UTF-8. صدّر ملفات Excel إلى CSV UTF-8 قبل استيرادها.
- ملف HTML الأصلي يستخدم روابط CDN خارجية؛ لذلك يتطلب اتصالًا عند فتحه كما هو. التطبيق الافتراضي يستخدم الصفحة المحلية بدل هذا الملف.
- ملف CSV التصدير متوافق مع Excel.

## تنبيه أمني وخصوصية

المستودع عام. لا ترفع بيانات أشخاص أو سجلات قانونية حقيقية إليه. رمز PIN داخل صفحات HTML ليس حماية أمنية حقيقية، وبيانات التطبيق لا تُشفّر؛ لا تستخدمه لتخزين بيانات حساسة قبل إضافة حماية وتقييم أمني مناسب.
